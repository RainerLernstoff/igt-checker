Rechtwinkeliges Dreieck

c = Hypotenuse (die lange Seite, gegenüber vom rechten Winkel)

c = √(a² + b²)

Umgeformt: a = √(c² − b²) und b = √(c² − a²)

√ = Wurzel, ² = hoch 2 (die Zahl mal sich selbst). Beide Tasten hat der Taschenrechner. Achte auf gleiche Einheiten!

Zusammengesetzte Fläche

Die Umfangslänge ist alles rundherum zusammengezählt:

L = a + 2 · b + c

Der Bogen a ist ein Halbkreis. Sein Durchmesser ist so lang wie c:

a = c · π : 2
